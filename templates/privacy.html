Privacy Policy

What RentWise stores, and why.

RentWise stores your name, email, phone (if provided), and password (as a salted hash, never in plain text) to run your account. It stores the properties you save, visits you schedule, and reviews you post so those features can work.

This data is not sold or shared with any third party — this is a personal project with no advertising or external data partners. The AI features (property search, chatbot) send your query text to Google's Gemini API to generate a response; no account data is sent beyond what a given request needs.

A fuller version of this page is planned as part of a later polish pass on the project.
